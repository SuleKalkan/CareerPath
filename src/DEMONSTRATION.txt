CAREERPATH FEATURE DEMONSTRATION
Interactive roadmap and cybersecurity skill matching


1. USER STORY

Source: Issues.md, Issue 1 - "Preparing and organizing" (James), size: large

As a student, I want to be able to organize the skills I need to learn on a roadmap
so I am prepared for the cybersecurity position I want.

Requirements:
- Roadmap that a user can interact with
- Adding skills to the roadmap
- Seeing how those skills match up to the desired position

Acceptance Criteria (as recorded in Issues.md):
[x] User can add/remove tasks
[x] User's skill match updates with new skills/less skills.

4. IMPLEMENTATION - LIVE APPLICATION DEMONSTRATION


Demonstrated flow:
1. Open Explore jobs and view Cybersecurity Analyst Intern at Bank of America.
2. Its initial skill match was 20% (1 of 5 skills).
3. Add "Networking" from the missing skills list.
4. Open My roadmap and expand upcoming activities. "Develop Networking" appears
   as a planned skill and Networking is labeled Planned in skill coverage.
5. Open that activity and advance it from Not started to In progress, then Completed.
6. Networking is then labeled Completed and the job match rises to 40% (2 of 5).
7. Remove the completed activity. The roadmap updates and the job match returns
   to 20%.


5. TESTING - ACCEPTANCE CRITERIA

Acceptance criterion: User can add/remove tasks.
Result: Correct - Adding the missing Networking skill created a roadmap activity.
Removing the completed activity removed it from the roadmap and skill coverage.

Acceptance criterion: User's skill match updates with new skills/less skills.
Result: Correct - The Cybersecurity Analyst Intern match changed from 20% to 40%
when Networking was completed, then returned to 20% when the activity was removed.

Manual reproduction:
- Run "npm install" once, then "npm run dev".
- Follow the demonstration steps in section 4.
- Compare the match percentage and skill coverage before and after each change.
